# Phishing URL Detection System

## About the Project
This project detects whether a URL is legitimate or potentially
a phishing URL.

## Features
- Detects suspicious URLs
- Helps identify potential phishing websites
- Simple and user-friendly interface

## Technologies Used
- Python
- Machine Learning
- Streamlit

## How to Run
1. Install Python.
2. Install the required dependencies:
   pip install -r requirements.txt
3. Run the application:
   streamlit run app.py
